# Public software working agreement

Android source: apps/mobile. Shared fictional cases and formative rubric: packages/core.
The phone calls configured APIs directly; server/ is optional legacy functionality.
Read README.md, docs/OPEN_SOURCE_STATUS.md and docs/ASSESSMENT_SPOTCHECK.md first.
Preserve SIMULATED_ONLY boundaries and raw AI output separately from teacher review.
Do not call automatic scores validated or infer teaching efficacy from software tests.
Never commit provider keys, .env, signing keys, device exports, or identifying data.
Run npm ci, npm run typecheck, npm test, npm run build as appropriate for code changes.
Live API checks incur cost and require explicit authorization and a dedicated test target.
Keep upstream licenses and attribution. Preserve previous releases and evidence.
