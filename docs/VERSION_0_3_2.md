# v0.3.2 使用变化与版本说明

公开标签：`v0.3.2-alpha.1`。App版本：`0.3.2`，Android版本码：`6`。这是Android调试预发布包，手机直接连接所配置的API，记录保存在本机。

## 从问诊到下一次练习

学员完成语音或文字问诊后，先提交自己的病史总结、判断依据、计划和不确定之处，再查看反馈。总结输入后保存草稿；保存失败会保留输入并提供重试，离开前提示处理未保存内容。提交成功后总结锁定，后续生成或重试反馈使用同一份总结。

在“设置 → 评分设置”中，可分别选择日常练习和研究用途的反馈生成方式。默认日常练习自动生成、研究用途手动生成。开始训练时固定本次方式；手动模式先保存总结，需要时再点击生成AI反馈。自动模式也可选择“只保存总结，暂不生成反馈”。没有可靠的学员问诊原文时，只保存总结。

已有反馈的记录会在本机整理问诊结果说明，呈现实际完成的行为、需要继续练习的问题和相应原文。点击能够可靠定位的引用可回看发言。整理结果说明不额外调用模型，也不重算历史分值；生成新的AI反馈仍会调用所选API。

## 教师复核

教师可逐项填写修正分、理由和整体意见。原始AI分与原始反馈保留，历次教师复核分别保存；历史中可查看每版采用的修正及理由。复核编辑尚未保存时，关闭表单会提示继续编辑或明确放弃。

教师标识由使用者人工填写，时间来自设备时钟。这是本机教学复核记录，正式研究中的独立考核仍应按研究方案另行安排。引用能定位到原文，并不保证模型正确理解了该行为。

## 记录与科研工作区

- 首页可继续处理待写总结、待生成反馈和待教师复核的旧记录，沿用原会话固定的对象。
- “记录与待办”可按处理步骤检索，再按用途、学员编号或关键词、项目、教师复核、病例、训练阶段及日期筛选。
- 科研工作区分为概览、学员、采集准备和数据，分别完成登记、下次训练设置、快照核对及导出恢复。
- 会话开始时的项目、学员、模型、病例和版本快照保留；修改登记名称不追溯改写历史。待办条数是会话记录数，不是学员人数或研究完成率。

## 异常资料与恢复

读取失败的草稿保留原文件，读取成功前暂停编辑。一份异常草稿不再阻断其他可读资料导出。正常备份与已取得的异常恢复原文分别处理：单项目或单会话导出不夹带无关异常资料，全量恢复导出另列其范围。存在异常时请核对导出说明，不能将可读部分当作完整备份。

JSON恢复不包含WAV、API Key、下次训练绑定或本机反馈偏好。ZIP未加密，分享后还需在接收位置确认保存。具体操作见[用户指南](USER_GUIDE.md)。
