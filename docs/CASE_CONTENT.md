# 教学病例内容与证据边界

这四例均为编写的虚构病例，未使用实际患者资料；时间、年龄、症状组合和生活史是教学情境设定。它们用于检验软件能否保持患者角色、按问题披露信息、保存对话并支持复核，尚未经过本地专家共识或教学测量学验证。

| 病例 | 本次训练关注 | 原型中的限制 |
|---|---|---|
| 右上腹痛 | 疼痛要素、伴随症状、既往类似发作 | 不把主诉或结石病史直接等同于确诊；本次查体/实验室/影像均为未知 |
| 发热伴黄疸 | 腹痛—发热—黄疸的先后、病情变化、胆道操作史 | 不由患者自行报告胆管炎分级；需区分问诊线索与实际生命体征/器官功能数据 |
| 上腹痛 | 围绕短回答追问、酒精和代谢线索、已知/待查 | 未提供胰酶及影像，不由一次症状问诊确诊胰腺炎 |
| 无痛性黄疸 | 进展、尿便和体重变化、用药、患者担忧 | 无痛或消瘦不能单独证明恶性，未提供病理或影像 |

背景核对采用以下可追溯资料。它们支持一般症状与诊断资料边界，不代表认可本软件的病例效度、量规或自动反馈：

- [2020 WSES急性结石性胆囊炎指南正文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7643471/)：病史、查体、实验室和影像需结合判断，单一症状并非充分诊断依据。
- [Tokyo Guidelines 2018胆管炎诊断及严重程度分级原文](https://onlinelibrary.wiley.com/doi/10.1002/jhbp.512)：用于核对诊断与严重程度的资料类型；此次网页检索含摘要/题录信息，未将量规写成TG18原量表。
- [ACG 2024急性胰腺炎指南题录及摘要](https://pubmed.ncbi.nlm.nih.gov/38857482/)：用于确认指南版本与适用主题；未将摘要扩写为详细处置规则。
- [NICE NG12胰腺癌转诊识别建议](https://www.nice.org.uk/guidance/ng12/chapter/Recommendations-organised-by-site-of-cancer)：用于黄疸/消瘦等需进一步评估线索的背景核对，不将英国转诊路径直接作为本地临床操作规程。

自动反馈仅评价已保存的问诊过程，引用必须能定位到原文。未记录、转录未完成、被打断的回答应保守处理。评分效度、不同病例的难度等价性及学习效果，均留待课题实施时用独立考核验证。
