## 使用前仍需验证的事项

自动分偏高和遗漏跨轮次证据仍存在，详见[评分抽查](ASSESSMENT_SPOTCHECK.md)。教师修正功能和更严格的引用检查不证明模型评分已经有效。正式考核、评分者校准及教学效果需独立研究。

本轮没有新增真实API或物理手机验收。麦克风、外放/回声、蓝牙、后台/来电、院内网络、接收端保存和多手机汇总需按实际设备检查。Qwen仅保留指定配置的历史真实API记录；其他服务商适配不能等同真实账号已通过。教师人工标识及设备时间也不是医院身份认证或独立盲评。
