# 首次真实反馈的文字一致性抽查

日期：2026-10-21。对象为合成语音和虚构病例产生的测试会话 `ad316cb0-8da0-4516-a638-def0749e394c`。原始反馈保存在专用测试数据目录；链路收据见 `artifacts/ui/browser-audio-e2e.json`。

本次检查只将模型评论与本项目预设行为锚点、实际对话文字对照，不代表带教专家评分，也不建立量规效度。

## 实际观察

- 本次患者回答中，疼痛时间、油腻饮食诱因、已测体温、胆石症病史、氨氯地平及手术担忧与固定病例资料一致；语音转录与Flash回答均通过文本一致性检查。本次样本未覆盖其他三例或各种追问、诱导及打断方式。
- 反馈项目完整，所有展示的引用都能定位到实际完整发言。来源、版本、未计分项和两组覆盖范围均被保存。
- **“患者想法、担忧与期待”被给2分，评论称学员“承接了患者的表达”。** 本段学员只问“您最担心什么？”，随后患者回答担忧即结束；没有后续学员核对或承接。根据当前满分锚点，该项存在给高及评论超出原文的可能，应交教师复核。
- **“结束小结、核对与说明待查”被给2分。** 引用支持下一步计划及邀请补充，未显示对已获病史的实际概括。按当前要求三项同时满足的满分锚点，更接近部分完成，需教师判断。
- **“从开放到针对性追问”未能评分。** 原始记录实际包含开放问题和随后多个相关追问，提示模型也可能漏用跨发言证据。不能把未计分直接解释为学员没有完成该行为。

## 对首版的结论

Flash已完成病例应答和有出处的反馈生成，可以承担当前原型的病例内核与自动反馈草稿。引用校验只能验证出处和记录状态；它没有验证模型对行为的理解及分档是否正确。当前自动分值只用于形成性复盘并标为待教师复核，不能直接作为正式考试成绩。

下一步应由带教教师独立评价一批具有完整、部分、未观察及明确不当表现的录音/转录，锁定量规与模型版本，再比较条目级分档、一致性、错误归因和跨病例表现。应保留本次原始偏差作为校准样本，不用事后改写测试反馈制造一致。

## v0.2 手机独立版的再次观察

同日对原生手机直连样本 `8fc21bfb-e802-4577-9430-4ed62e83c6fd` 再作文字抽查。资料为虚构病例、合成语音和软件验收提问，原始结果保存在 `artifacts/standalone/android/synthetic-session.json`。这不是新增住培研究样本，也不是专家金标准评分。

本版提示词已强调满分须满足全部锚点、不能把未来计划当作已作病史总结，也不能把询问担忧当作随后承接。实际结果中，“结束小结、核对与说明待查”给1分，并明确指出没有概括已获病史，符合该处只部分完成的文字观察。

仍有未解决的语义偏差：“患者想法、担忧与期待”给2分，引用只有“您最担心什么？”，没有其后学员承接患者回答；“开放起始与就诊议题”给2分，评论以“隐含”议题关注代替明确核对依据；“从开放到针对性追问”仍未计分，尽管存在开放问题及后续相关追问。前两项可能偏高，后一项可能漏用跨轮次证据。原始分值和原文均保留，没有为形成一致结果而改写。

因此，当前Flash可以用于病例回答和自动反馈草稿；自动分值不能直接作为教学研究的已验证能力结局。评价研究应保留原始预评，另设教师独立评价与分歧处理；模型ID、提示词和量规版本要记录，模型名称本身也不保证服务商底层权重在研究期内不变。是否达到正式评价用途，需依据校准结果另行判断。
